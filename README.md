# SiagaWARGA

A modern Community Security Application built with Next.js, Tailwind CSS, and Lucide Icons.

## Features Currently Implemented:
1. **Mobile-First App Shell**: Looks and behaves like a native mobile app.
2. **Panic Button (Home)**: High-visibility emergency alert system with a simulated cooldown mechanism.
3. **Incident Reporting**: Form to quickly upload suspicious activities or emergencies.
4. **Emergency Contacts**: One-tap access to police, security pos, medical, and community leaders.
5. **Resident Profile**: Manage household information.

## How to run locally:
```bash
npm install
npm run dev
```
